# Hey Argon / hands-free mode retired

VANTA no longer runs wake-word detection or continuously listens in the background. Picovoice setup and the `PICOVOICE_ACCESS_KEY` secret are no longer required.

Use VANTA's in-app tap-to-talk microphone control when you want to speak. The microphone permission remains available for that user-initiated voice input. Scheduled routines continue to be restored after device reboot; boot no longer starts a microphone service.
